# Lazarius Video AI

Agent open source de génération vidéo IA.

## Objectif
Transformer une idée ou un prompt en vidéo complète : scénario, storyboard, génération visuelle, voix, sous-titres et montage.

## Architecture initiale
- `backend/` : API FastAPI et agents IA
- `frontend/` : interface web
- `workflows/` : workflows ComfyUI
- `scripts/` : installation et démarrage
- `storage/` : fichiers temporaires et sorties

## Philosophie
Le mode par défaut privilégie les modèles open source exécutés localement. Les services commerciaux éventuels sont optionnels.
